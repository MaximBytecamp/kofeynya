# Кофейня «Зерно»

Учебный сайт для домашнего задания по темам 2.1–2.3
справочника по Git и GitHub.

## Файлы

- `index.html` — главная страница: описание, часы работы, разделы сайта
- `menu.html` — меню с ценами
- `styles.css` — оформление всех страниц

## Как открыть сайт

Открыть `index.html` в браузере двойным щелчком.
